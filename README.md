# 刘念 · 个人设计作品集

React / Vite 静态作品集。包含工业设计、IP 形象、视觉传达与海报设计。

## 本地预览

```sh
npm ci
npm run dev
```

## GitHub Pages

仓库： https://github.com/ABYSM-ai/portfoli

上传本目录内容至 main 分支后，在仓库 Settings → Pages → Source 选择 GitHub Actions。
工作流会自动构建并发布到 https://abysm-ai.github.io/portfoli/ 。
该网址只有在工作流成功后才可访问。

本站部分背景视频使用外部原始视频链接；外部服务的可用性会影响视频加载。
素材来自作者已加入网站的作品和证书；本目录不含 WAYWE 原型源码、研究资料与制作临时文件。
